This page contains an intentional Reflected Cross-Site Scripting (XSS) vulnerability. Executing untrusted JavaScript directly from URL parameters allows third parties to perform arbitrary code execution in the context of your browser session. This can lead to session hijacking, cookie theft, data exfiltration, or malicious redirects.

This application is intended strictly for local testing, educational purposes, or isolated security demonstrations. Do not use this code on a public or production server.

URL JS Executor

If a ?js= parameter is present in the URL, it will execute immediately on load.

Example usage:

?js=alert('Hello%20World!')
